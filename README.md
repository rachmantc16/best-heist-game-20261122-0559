Midnight Vault Heist — a top-down stealth game: slip through the museum at night, read the guards' sweeping vision cones and the rotating security cameras, pocket gems from the display cases, steal the Star Sapphire from the vault, and reach the green exit before the alarm hits 100%. Tools cost loot: throw a decoy coin to pull a guard away, or jam the cameras for a few seconds. Two routes lead to the vault, bushes hide you, and sneaking (Shift) makes you harder to spot.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` directly. No build step, no network requests, no external assets; sound is synthesized with WebAudio.
